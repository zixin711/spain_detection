# 395nm 紫外数据采集协议

紫外荧光数据公开数据集里没有，必须自采。**v0.3 起不要求成对拍摄**，
单独拍紫外图标注即可；只有阈值标定环节需要一小批配对样本。

## 器材

- 395nm UV-A 手电（几十元级即可；机器人上用板载 395nm LED 阵列）
- 手机（记录型号，不同机型的传感器响应不同，最好固定一台）
- 可选：A4 白纸或标定卡（做尺寸参照）

## 安全（每次都要遵守）

- 不直视光源，不照射他人眼睛与皮肤
- 儿童与宠物回避
- 单次照射控制在数十秒内
- 建议戴防 UV 护目镜

## 拍摄要点

1. **关灯**，尽量排除其他光源（走廊灯、屏幕、窗外天光都会污染荧光信号）
2. 手电与墙面距离 30~50cm，光斑覆盖整个取景范围，避免只照亮中间一小块
3. 手机距墙 30~50cm，镜头正对墙面
4. **锁定曝光与白平衡**（iPhone 长按取景框出现 AE/AF 锁定；安卓在专业模式里手动固定 ISO 与快门）
5. 关闭闪光灯
6. 每个部位拍 2~3 张不同角度，但**记入同一个场景组**（清洗管线按场景分组划分训练/验证集，防泄漏）

## 记录字段（建议用同名 txt 或统一表格记录）

```
文件名, 拍摄日期, 部位(卫生间/窗台/衣柜背墙/地下室/厨房), 距离cm, 手电型号, 手机型号, 是否配对白光, 备注
```

## ⚠️ 先纠正一个常见误解

**霉菌在 395nm 下通常不是"发亮的黄绿荧光"，而是比墙面更暗。**

实测 5 组样张：黄绿荧光像素占比为 0，整幅画面都是蓝紫色相。真实机理是——
室内墙面涂料普遍含荧光增白剂，紫外下整面墙发蓝白光；霉菌吸收紫外、淬灭这层荧光，
所以**霉斑呈暗区**；菌落生长前沿的菌丝层会散射出**亮白色蕾丝状细丝**，非常有辨识度。

标注时按"暗斑本体 + 亮丝前沿"来圈，不要去找黄绿色。
（少数基材上确实会出现发射型黄绿荧光，遇到了也标进来，算法里保留了这条补充通道。）

## 类别与目标数量

| 类别 | 判断依据（都以"相对墙面的暗/亮偏离"为准） | 目标 |
|---|---|---|
| `fluor_point` | 零星点状暗斑，衰减很浅，白光下基本看不见 | ≥ 200 |
| `fluor_local` | 局域清晰的暗斑，与周围墙面边界明显 | ≥ 200 |
| `fluor_band` | 连续条带或块状暗区（常沿瓷砖缝、墙角分布），伴亮丝前沿 | ≥ 200 |
| `fluor_saturated` | 大面积深暗区，衰减很深 | ≥ 200 |
| `fluor_chaotic` | 剥落边缘杂乱明暗交错，伴凹凸不平的几何异常 | ≥ 200 |
| `fluor_artifact` | **干扰负类，最重要**：亮且平滑无纹理的区域 | ≥ 300 |

### fluor_artifact 要专门去拍

395nm 下会发荧光的远不止霉菌。不建这个负类，紫外模态的误报率会高到没法用。
按下面这个清单主动去找场景拍：

- 洗衣粉 / 清洁剂残留（荧光增白剂，亮蓝白色，非常显眼——注意它和"墙面本身的荧光"是同一类物质）
- 新刷的乳胶漆、腻子（部分含荧光助剂）
- 白色塑料件、PVC 线槽、开关面板
- 硅胶密封胶（尤其是新打的）
- 纸张、包装材料、白色毛巾
- 盐析结晶（返碱）
- 宠物尿渍

## L1 的标注方法（最难，周期最长，建议 M1 阶段就开始）

L1 定义是"白光下肉眼不可见"，所以**没有可靠的白光标签可以对照**。
唯一自洽的做法是时间序列反证：

1. 挑几处已知会长霉的潮湿部位（卫生间瓷砖缝、窗台结露处、衣柜背墙）
2. 现在就拍紫外图并记录位置，此时白光下看不出任何东西
3. 每 2 周复拍一次，持续 2~3 个月
4. 等某处白光下真的长出可见霉斑，回头把当初那张紫外图上对应位置的荧光点标为 `fluor_point`（L1 证据）
5. 始终没长霉的荧光点，大概率是 `fluor_artifact`，同样是宝贵的负样本

这条链路周期长，越早开始越好，不要等到要训紫外模型时才想起来。

## 补充采集重点（基于首轮标定的发现）

首轮已用 5 组 L1~L5 配对样张完成标定，全部等级都能复现，但每级只有 1 组，统计意义很弱。
按优先级补充：

1. **不同墙面材质**（乳胶漆 / 瓷砖 / 壁纸 / 水泥 / 石膏板）—— 涂料里荧光增白剂含量差别很大，
   直接决定"墙面基线亮度"，这是当前算法最大的不确定性来源。
2. **更多 L1 样本** —— 最难采也最有价值，方法见上面的时间序列反证法。
3. **带明确空鼓/剥落的 L5 样本** —— 现有 L5 样张只是覆盖极广，没有结构破坏的直接影像证据，
   系统因此只敢给 [L4, L5] 区间。
4. **同一面墙的不同拍摄距离与角度** —— 验证阈值对拍摄条件的稳健性。

## 配对标定子集（150~300 组）

放到 `data/paired_calib/white/` 与 `data/paired_calib/uv/`，**同名文件视为一对**。

拍法：同机位先开灯拍白光，再关灯开紫光拍第二张，中间尽量不移动手机。
用途只有一个——拟合 `A_uv ≈ k · A_white + b`，把紫外的面积阈值标定出来
（紫外荧光区通常大于白光可见区，直接套用 5%/30% 会系统性高估等级）。

```bash
python scripts/calibrate_grading.py          # 先看拟合效果
python scripts/calibrate_grading.py --write  # 回写 configs/grading.yaml
```
